# 종이컵 B200 best 모델 로컬 실행

로컬 VS Code에서 `run.py`를 열고 **Run Python File** 버튼을 누릅니다. 추가 옵션은 없습니다.
Python 인터프리터는 `D:\lerobot-2026\.venv\Scripts\python.exe`를 사용합니다.

모델 확인 후 follower와 카메라를 연결하고 미리보기 창을 엽니다. 기존 인형 실행기와 같이
HOME 부근에서 **SPACE**를 누르면 동작합니다. **P**는 일시정지, **Q**는 HOME 복귀 후 종료,
**E**는 긴급 torque-off입니다. 기본은 1회, 최대 60초입니다.

- 모델: B200 종이컵 본 학습의 `044000`, 검증 50개 최저 손실 `0.1889892668`
- 데이터: `robot_datasets/tasks/pick_paper_cup/dataset` (250개, 152,131프레임)
- 학습/검증: 200/50, 서로 겹치지 않는 에피소드 분할
- 정규화와 행동 제한: 해당 모델의 저장 processor와 학습 200개에서 계산한 통계
- 입력: TOP/SIDE RGB + 관절 6축. depth·부하·전류 미사용
- 설정: 현재 `collection/settings.json`의 카메라·포트·HOME 사용
- 추론: 로컬 CUDA FP32, 30Hz 제어, 60프레임 재계획과 8프레임 전환 보간
- 인형 실행기의 속도·관절 범위·추적오차·멈춤 감지와 HOME 복귀를 재사용
- 인형 전용 그리퍼 조기 닫힘 보정은 끔

모델·정규화·통계 파일은 서버 원본과 SHA-256을 비교합니다. 번호 체크포인트는 로컬
`checkpoints/044000/pretrained_model`에 있으며 큰 모델 파일은 Git 제외 규칙에 해당합니다.

`check_model.py`는 로봇을 연결하지 않는 검사입니다. 모델을 strict reload하고 보정 파일과
메타정보를 확인하며, 검증 50개 중 고르게 고른 10개에서 각 3개 시점(총 30개)을 추론합니다.
결과는 `model_check_result.json`에 저장합니다. 이는 전체 검증 재평가나 실제 파지 성공률이 아닙니다.
이 작업에서는 실제 로봇을 연결하거나 움직이지 않았습니다.

## 자동 종료

종이컵은 기존 동작 완료 HOME 기준에 도달하면 추가 RELEASE 입력 없이 토크를 해제하고 종료합니다. HOME 밖이면 기존 복귀 동작을 먼저 수행합니다. HOME 복귀 실패 시에는 토크를 임의로 풀지 않고 오류를 표시합니다. 카메라 정리는 최대 2초 기다린 뒤, 정상 종료 시 남은 SDK 스레드 때문에 프로세스가 남지 않도록 끝냅니다. 인형 기본 종료 방식과 종이컵의 파지·추론·주행 설정은 유지합니다.
