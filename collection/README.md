# 데이터 수집

**`수집 실행` 바로가기를 더블클릭하세요.**

또는 `collect.py`를 열고 편집기의 ▶ 실행 버튼을 누르면 같은 창이 열립니다. 프로젝트 가상환경은 자동으로 선택합니다.

1. 창에서 작업을 선택합니다: 인형 / 종이컵 / 분류 / 상자 2·3·4개 쌓기.
2. 로봇을 HOME 근처에 두고 **수집 시작**을 누릅니다.
3. **준비 5초 → START 화면 1초** 뒤 녹화가 시작됩니다.
4. HOME에서 벗어나 작업한 뒤 HOME으로 돌아와 **2초 유지하면 자동 저장**합니다. 최소 녹화 시간은 8초입니다.
5. 끝낼 때 **종료**를 누릅니다. 창을 닫아도 정리 완료 후 종료합니다.

실패한 시연은 자동 저장 조건에 도달하기 전에 **폐기** 버튼 또는 영상 창의 `f`를 누르세요. 바로 준비 화면으로 전환하고 **10초 후 같은 번호로 재시도**합니다. `q` 또는 종료 버튼은 현재 미저장 시연을 폐기하고 종료합니다. 이미 저장을 시작했다면 저장 완료를 기다린 뒤 종료합니다.

기존 auto_home과 같이 저장은 다음 준비 5초와 동시에 진행됩니다. 저장·검사가 더 오래 걸리면 완료될 때까지 기다린 뒤 START 1초로 넘어갑니다. 준비 중에는 검은 배경의 숫자 카운트다운, START 때는 큰 START 문구를 표시합니다. 저장 중에도 카메라 화면 갱신과 텔레오퍼레이션을 유지합니다. 데이터 사본 준비가 필요하면 START 전에 잠시 지연될 수 있습니다.

영상 누락·속도 저하가 감지된 시연은 실패 표시를 유지하고 HOME 복귀 또는 시간 초과 시 폐기하며 10초 후 재시도합니다. 작업별 최대 녹화 시간은 settings.json의 기존 설정을 사용합니다. 수집 창을 여는 것만으로 로봇은 연결되지 않습니다. ‘수집 시작’을 누르면 장비에 연결하고 텔레오퍼레이션이 시작됩니다.

## 파일

- **collect.py**: 사용자가 실행하는 수집 창
- **core.py**: 수집·검증·중단 복구를 합친 내부 코드
- **settings.json**: 6개 작업 문장과 장비 설정
- `tests`, `reports`: 개발 검증과 실행 기록. 평소에는 열 필요가 없습니다.

터미널 관리 도구와 이번에 만든 모델 학습 실행기는 제거했습니다. 기존 ACT 학습 결과와 기존 100개 시연은 그대로 보관합니다.

## 저장과 재개

원본은 `D:\lerobot-2026\robot_datasets\tasks\작업이름\dataset`에 저장합니다. 창에서 저장 경로와 시연 수를 확인할 수 있습니다. 같은 작업으로 다시 시작하면 다음 시연부터 이어집니다.

각 작업의 자연어 문장, TOP/SIDE RGB, TOP depth, 관절 상태와 action을 기존 LeRobot 형식으로 저장합니다. 데이터는 추후 ACT와 SmolVLA에서 재사용할 수 있습니다. 개별 데이터셋의 로컬 `task_index=0`은 정상이며, 작업 문장으로 서로 구분합니다.

시작·저장 시 무결성 검사, 영상 누락과 느린 수집 감지, 저장 공간 확인, 장비 중복 실행 방지를 유지합니다. 중단된 저장이 있으면 시작 버튼에서 복구를 시도하며, 실패 상태 원본은 별도 폴더에 보존합니다. 복구 실패 시 수집을 시작하지 않고 오류를 표시합니다. 작업 문장·보정값·장비 설정이 달라지면 기존 데이터에 섞어 저장하지 않습니다.

기존 `episode_sample_dataset/auto_home_collection/auto_home_record.py`의 검증된 장비·인코딩 도우미를 계속 사용하므로 해당 파일은 유지합니다. 기존 수집 프로그램과 새 수집 창에서 동시에 수집하지 마세요.
