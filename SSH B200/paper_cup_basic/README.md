# 종이컵 ACT 본 학습과 검사

## 실행 버튼으로 본 학습 시작

SSH B200의 VS Code 원격 창에서 `train.py`를 열고 **Run Python File** 버튼을 누릅니다.
인터프리터는 `/NHNHOME/workspace/lerobot/lerobot-act/bin/python`을 선택합니다.
명령행 옵션은 필요하지 않습니다. 이 파일을 실행하면 실제 50,000-step 학습이 시작됩니다.

- 서버 코드: `/NHNHOME/workspace/lerobot/experiments/act/paper_cup_basic/train.py`
- 데이터: `/NHNHOME/workspace/lerobot/datasets/paper_cup/dataset/`
- 결과: `/NHNHOME/workspace/lerobot/outputs/act_paper_cup_basic_날짜_시각/`
- 실행할 때마다 새 결과 폴더를 만들며 기존 결과를 덮어쓰지 않습니다.
- 중복 실행은 잠금으로 차단합니다. 중단 후 재실행은 처음부터 새 학습이며 자동 재개가 아닙니다.
- 원격 터미널 실행이므로 SSH 연결 종료 후 지속 실행까지 보장하는 방식은 아닙니다.

## 본 학습 설정과 이유

| 항목 | 값 | 이유 |
|---|---|---|
| 학습 / 검증 | 200개 / 50개 | 수집 세션별로 고정 분할, seed 1000 |
| 학습 step | 50,000 | 인형과 동일한 초기 기준. 성능에 충분한지는 검증 곡선으로 판단 |
| batch | 8 | B200 48-step 실측에서 16과 처리량이 비슷하고 GPU 메모리는 더 적음 |
| workers / prefetch | 4 / 2 | 실측 통과. 미리 읽는 배치 수를 제한 |
| 학습률 / 정밀도 | 1e-5 / FP32 | 기존 ACT 기본값 유지. 배치 확대와 학습률 변경을 동시에 하지 않음 |
| 평가 / 저장 | 2,000 step | 본 학습에서는 검증 50개 전체 사용. 전체 평가 비용과 체크포인트 수를 제한 |
| 로그 | 100 step | 손실·데이터 대기·처리량을 추적 |
| 모델 / 입력 | ACT, ResNet18, RGB 2개 + 관절 6축 | 인형과 같은 기준 모델, 종이컵 데이터로 처음부터 학습 |
| chunk / n_action_steps | 100 / 100 | 기존 설정 유지. 정밀 파지에 최적인지는 별도 실제 평가 필요 |

학습 시연만의 통계를 계산해 학습·검증에 공통 적용합니다. 깊이·부하·전류는 정책 입력에서 제외합니다.
50,000 × 8 = 400,000개 시작 프레임 샘플을 사용합니다.
셔플 샘플링과 겹치는 action chunk가 있으므로 각 프레임을 동일한 횟수로 본다는 뜻은 아닙니다.
낮은 검증 손실의 체크포인트와 실제 파지 성공률을 함께 확인해야 합니다.

## 2026-10-21 배치 비교

두 설정 모두 48 step, 검증 2개, FP32, workers 4, prefetch 2로 학습·검증·저장까지 통과했습니다.

| batch | 최대 PyTorch GPU 할당량 | 초기 로딩 후 로그상 처리량 | 전체 비교 실행 시간 |
|---|---|---|---|
| 8 | 약 4.01GB | 약 96–121 샘플/초 | 34.4초 |
| 16 | 약 7.36GB | 약 107–118 샘플/초 | 36.9초 |

배치 16이 두 배의 샘플을 처리하지만 한 step의 데이터 대기도 길어져 지속 샘플 처리량은 비슷했습니다.
짧은 비교이며 장시간 처리량이나 파지 정확도의 우열을 입증하지 않습니다.

## 최저 검증 손실 모델

2,000 step마다 검증 50개 전체의 손실을 평가하고 체크포인트를 저장합니다.
그중 유한한 검증 손실이 가장 낮은 모델은 `checkpoints/best/pretrained_model/`로 접근합니다.
`best.json`에는 선택한 step·검증 손실·실제 체크포인트 경로를 기록합니다.
`checkpoints/last/`는 최신 모델이며 best와 다를 수 있습니다.
단계별 체크포인트는 모두 보존하고 best 연결만 원자적으로 갱신하므로 모델을 중복 복사하지 않습니다.
동일한 손실이면 먼저 선택한 모델을 유지하며 NaN/Inf는 best로 선택하지 않습니다.
설치된 LeRobot 파일은 수정하지 않습니다. 공식 학습 함수의 메모리 내 복사본에 검증 결과 콜백과
저장 후 선택 기능만 연결하며, 지원하던 검증 위치를 찾지 못하면 학습 전에 중단합니다.
이 기능은 다음 실행부터 적용됩니다. best는 검증 손실 기준이며 실제 파지 성공률 기준은 아닙니다.
